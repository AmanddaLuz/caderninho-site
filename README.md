# Caderninho — Site

Landing page de divulgação do Caderninho, app Android de controle de vendas
fiado com cobrança automática via WhatsApp.

- `index.html`: site estático (sem build step), hospedado via GitHub Pages.
- `assets/`: ícones e artes promocionais.

## Identidade visual

Paleta e estética reaproveitadas do app e da página de política de
privacidade (`caderninho-privacy`): papel de caderno (`#fffdf7`), tinta azul
(`#184e77`/`#285a8a`), margem vermelha (`#d86b62`) e linhas de pauta
(`#8cb4d9`). Suporte a modo escuro via `prefers-color-scheme`.

## Pendências antes do lançamento

- Substituir o botão "Em breve na Play Store" pelo link real assim que a
  versão de produção for publicada.
- Substituir o link de contato via WhatsApp (`wa.me/55XXXXXXXXXXX`) pelo
  número oficial de suporte.
- Trocar as prévias de tela ilustrativas pelas capturas reais do app quando
  disponíveis.
